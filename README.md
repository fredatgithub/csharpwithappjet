# # Prime Number Calculator

A professional C# console application with a beautiful Material Design web interface for calculating prime numbers.

## Features

- **Efficient Prime Calculation**: Optimized algorithm for checking prime numbers up to very large values
- **Material Design UI**: Professional, polished interface following Google's Material Design guidelines
- **Real-time Results**: Instant prime number verification with detailed explanations
- **Factor Analysis**: Shows all factors for non-prime numbers
- **Responsive Design**: Works beautifully on desktop and mobile devices
- **Smooth Animations**: Material Design animations and transitions

## Technology Stack

- **Backend**: C# (.NET 8.0) with ASP.NET Core
- **Frontend**: Pure HTML, CSS, and JavaScript with Material Design
- **Deployment**: Docker containerized application

## Prime Number Algorithm

The application uses an optimized trial division algorithm:
- Handles edge cases (numbers ≤ 1, number 2)
- Only checks odd divisors up to √n
- Efficiently finds all factors for composite numbers

## Design Features

- **Material Design Cards**: Elevated surfaces with proper shadows
- **Vibrant Color Palette**: Primary colors with proper contrast
- **Smooth Animations**: Slide-up cards, ripple effects, shimmer animations  
- **Typography**: Roboto font family with proper hierarchy
- **Interactive Elements**: Hover effects and state transitions
- **Responsive Grid**: Proper spacing and alignment
- **Loading States**: Professional loading indicators

## Usage

1. Enter any positive integer
2. Click "Check Prime" 
3. View detailed results with explanations
4. See factors for non-prime numbers

The interface provides immediate feedback and handles edge cases gracefully.
